# Rotion

Rotion is a planned local workspace app for macOS. It will use AnomalyCo's Rune UI framework.

Status: product interview and Notion UI study. App implementation has not started.

## Confirmed direction

- macOS desktop is the first release target.
- V1 uses local storage. It needs no account or sync.
- V1 includes the full personal workspace engine. It includes pages, retained database views, properties, formulas, relations, rollups, linked databases, filters, sorting, and templates. Form views are excluded from v1.
- Use an app-managed local database, a folder for attachments, and import and export.
- The design system has first priority. Remove separate product promotions and excess interface elements.
- Use almost no animation. Follow Emil Kowalski's principles for frequent actions and keyboard input.
- Study Notion states before the full PRD and implementation.
