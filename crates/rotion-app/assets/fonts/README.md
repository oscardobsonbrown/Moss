# Geist font files

These unmodified fonts come from [vercel/geist-font](https://github.com/vercel/geist-font), revision `ef2597cfc42f4797676df105517ccc0a1cfa6569` (retrieved 2026-11-07).

- Geist.ttf and Geist-Italic.ttf: variable Geist Sans, internal family `Geist`.
- GeistMono.ttf and GeistMono-Italic.ttf: variable Geist Mono, internal family `Geist Mono`.
- GeistSerif.ttf: regular Geist Serif, internal family `Geist Serif`.

The app embeds the font bytes. It does not fetch fonts or install them in macOS. The font license is separate from Rotion’s MIT source license. Keep both upstream notices, OFL.txt and LICENSE.txt, with these files. The macOS packaging script also copies them into the app’s Resources folder.

`sources.json` records the pinned download URLs and SHA-256 hashes. Serif is the upstream regular display face; no italic or variable-weight Serif face is included in this release.
