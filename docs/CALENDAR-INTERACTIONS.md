# Calendar view

The local `pass03-15-calendar-populated.png` and `pass03-16-calendar-no-date.png` captures show the month grid and No date panel. The [Notion Calendar view guide](https://www.notion.com/help/calendars), [calendar tips video](https://www.youtube.com/watch?v=ywoBpjXfuwQ), and [database tutorial](https://www.youtube.com/watch?v=1EVOg2w4Zlc&t=1394s) show the layout settings, card properties, page opening, and scheduling interactions. The references do not establish every hover, focus or drag state.

Moss uses the same page width as other database views for a seven-column grid with adjoining weeks, adjacent-month days, weekend shading, a Today marker, and controls on the right. Scroll to the edge of the current period, then continue scrolling to move to the next or previous month or week. Layout settings select Month or Week and the date property, or create a missing date property. The displayed position is saved per workspace and view. Visible calendar records and the No date count come from a background query over the matching database, rather than the loaded table page. No date search queries the full matching set. Users can create a page on a day, click or drag an undated page onto a day, move a dated card, and resize its date range. A moving card shows its icon and visible properties in the drag preview. Users can edit visible card properties and open a page in the view's selected mode. Date edits preserve time and metadata and reject conflicting changes. Multi-day cards span day columns and stack in lanes.

The visible interval loads up to 1,000 records at a time and provides paging when more match. The No date panel shows up to 100 results and supports search across the full matching set. The Settings switch changes the week start for Calendar, date pickers, and Dashboard calendars. Sunday is the default; automatic regional selection and continuous forward month scrolling are not implemented. Notion's hide-weekends and wrap-page-titles settings are not yet available. Exact native hover, focus, accessibility and physical-pointer behavior are not yet verified. The background query has not been profiled against a million-row database.

The November 14 card comparison uses the supplied Notion capture and a local sample with the same values. Calendar cards show custom page icons, render relation values as linked-page labels, and align cards in the same lane. Visible empty properties reserve card space; hidden properties do not. The sample was compared at the reference card width. The default page style uses Geist; serif and mono page styles use their selected fonts.
