## Evidence and geometry cautions

The older reference and Moss gallery screenshots have different pixel dimensions (3600 × 2260 and 2880 × 1800). The older reference did not record its logical viewport and backing scale. The current Notion 7.42.3 deep pass records a 2× display and a nominal 1800 × 1130 window; this does not retroactively establish older capture geometry. Match app window, content, theme and scale before calculating distances. The user's cropped table image shows the reported displaced text but lacks a full matched viewport. Stills cannot measure animation duration. `PERFORMANCE-RESULTS.md` is separate from visual evidence and must not be used to claim a rendered viewport meets timing targets.

## Implementation update after the source audit

The audit table above preserves the earlier state. The shared build now has stable Table cell geometry and cell traversal; Date, Status and Select pickers; direct Checkbox controls; formatted dates and safe relation labels; responsive Gallery cards with persisted size, preview and load limit; batch first-block previews; Calendar Today; and searchable Calendar/Timeline No date lists. Board and List reuse the property-value renderer. Save failure guards cover picker drafts, page creation, search navigation and view query rollback.

The latest combined run passed 58 app, 18 core and 7 engine tests, including minimum-window Date, popup hit-test, Timeline axis and motion checks. These checks establish their tested paths, not complete visual or behavioral parity. Native review verified Table creation and title alignment, Gallery page creation and saved body preview through AX, and a fresh six-week Date image. Native screenshots then became stale again.

The native study remains incomplete. Date ranges, time, reminders, detailed date settings, filtered creation, native Quit protection, and full-schema/view/editor functions remain open. See NATIVE-CLOSE-GAP.md for the failure case that can lose an unsaved draft during native termination. All ordinary and large-workspace visible timing targets remain unverified.

The sidebar now loads bounded sibling pages and expands document and database pages. It does not list record pages. A document whose parent is a database record remains reachable through indexed search, but it has no child-page link in the record editor yet. Add bounded child-page navigation to the open record before claiming complete tree navigation. The paging controls and expansion behavior are implementation choices; their Notion parity is not established.

Later corrections: Date ranges and optional times now have typed editing with metadata/offset preservation, full-precision ordering checks and atomic same-field conflict detection. Reminders, date-format controls, mixed precision and native commit/dismiss parity remain open. Sidebar and child-page queries are bounded; full Record pages now expose their direct child links. Stale cursors, child-title/focus refresh, initial child-query retry and failed-save navigation have regression checks. List/Gallery config edits and database creation are now atomic. The earlier gap notes remain historical; they do not describe these corrected paths.
